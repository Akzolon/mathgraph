### Structure of the answer

An example set:

$\{Dog, Cat, Mouse\}$

---

In the example set, the set is composed of two parts:

a)
- the elements that compose the set

$Dog, Cat, Mouse$

b)
- the elements that denote the set

$\{\}$

---

We can then study the set in the said two ways.

a)
- Studying the set [[Collective property|through the nature of its constituents]], what can we infer from it?

Questions like: 
- What kind of [[Entity|entities]] compose this set or category?
- Are there [[Property|distinguishing characteristics]] which warrants their grouping?
- Do they fit a [[Superset|wider set|]]?

are questions about the [[Collective property|collective nature of a set]].


b)
- Studying the set [[Common property|as a single whole]], what can we infer from it?

Questions like: 
- How [[Absolute Cardinality|many members compose]] this set or category?
- Is the aforementioned set [[Cardinal Finity|finite]]?
- Is the aforementioned set [[Empty Set|empty]]?

are questions about the [[Common property|common nature of a set]].
